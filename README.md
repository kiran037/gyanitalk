# 🔮 GyaniTalk Admin – Next.js Astrology Admin Dashboard

**GyaniTalk Admin** is a fully featured, open-source **Next.js** admin dashboard tailored for managing astrology platforms. Packed with 200+ UI components, powerful integrations, and beautifully designed pages, it's the perfect foundation for running and scaling GyaniTalk’s internal operations.


Whether you're managing astrologers, users, horoscopes, or transactions — GyaniTalk Admin gives you complete control with performance, security, and a modern UI.

## ⚙️ Installation

```bash
# Clone the repo
git clone https://github.com/gyanitalk/gyanitalk-admin.git
cd gyanitalk-admin

# Install dependencies
npm install
# or
yarn install

# Start development server
npm run dev
# or
yarn dev
